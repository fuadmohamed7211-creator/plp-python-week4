# Week 4 Assignment: Hands-On Lab - Grades, Eligibility & Smart Decisions

## Overview
This repository contains Python scripts demonstrating basic function definition, parameter passing, return statements, and default arguments.

## Files Included
* `welcome.py`: Defines a function that takes a person's name and returns a formatted welcome message string.
* `toolbox.py`: Implements three utility functions (`double`, `is_pass`, and `greet`) to handle basic math, comparison operations, and string formatting.

## Reflection
The hardest function to write was `greet` because it required understanding how to set a default value for the `greeting` parameter while still allowing custom values to override it when passed.
